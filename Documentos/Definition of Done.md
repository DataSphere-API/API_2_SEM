#### Definition of Done (DoD) <a id="dod"></a>

- O código passou por revisão de outro membro do time 
- Os commits estão claros e seguem o padrão convencional.
- O código realiza tratamento das devidas exceções.
- Passou por pull request para a branch principal aprovado pelo P.O.
- A tela em JavaFX corresponde ao esboço que foi aprovado.
